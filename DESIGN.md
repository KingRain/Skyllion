# Skyllion — Style Reference (Superr / Refero)
> Warm schoolyard notebook in soft afternoon light: cream page, orange marker, thin dark ink borders. Source: https://styles.refero.design/style/cfd0fec1-f25a-4b9b-9bd0-d5b66960f2f2

The pixel-art sky (scene, planes, tiers) stays; all UI chrome (panels, buttons, type) follows this system.

## Color
| Token | Hex | Use |
|---|---|---|
| Cream Paper | #fdfbf9 | canvas, cards, button fills |
| Dew Drop | #f7efe9 | secondary surface tint |
| Charcoal | #171717 | all text, borders, strokes |
| Cocoa Ink | #2b1a07 | headlines |
| Marker Orange | #ff6f1e | captions, emphasis underline, accents only |
| Burnt Sienna | #ce500a | orange needing weight on cream |
| Sky / Bubblegum / Sprout | #3b82f6 / #ff66cf / #22c55e | decoration only, never functional UI |

## Type
Display: Fraunces (substitute for gelica), 400–600, lowercase, normal tracking, line-height 1.1–1.2. Body/UI: Inter (substitute for Geist), 400–500, line-height 1.5. Scale: Minor Third from 20px.

## Shape & spacing
Base unit 4px, card padding 32px (16px on mobile), element gap 12px, max width 1200px. Radius: inputs 8px, cards 12px, buttons/tags 20px.

## Do / Don't
- Buttons are a dark border on cream, never a solid fill. Matte surfaces, minimal shadow.
- Orange only for captions, highlights, brand accents.
- No capitalised headlines, no letter-spacing.
